Step by step

  1. Download the .tif (or .zip) from the home page.
  2. Sign in at the competition.
  3. Click Submit → Make new submission.
  4. File to submit: choose the downloaded file. The form accepts a single-band GeoTIFF or a .zip containing one.
  5. Note (optional): paste the suggested note shown with the file (strategy + sha) so submissions stay identifiable.
  6. Submit. If the form reports "Predicted values must be in range [0, 1]", the file has NaN inside the footprint — ours cannot: the writer refuses such files and the gate re-checks.

Slot strategy

Only 3 scored submissions per rolling 7 days. Spend slot 1 on the current file, read the public score, then decide. One submission is chosen blind (no private-score knowledge) for both prize rounds before Dec 3 2026. Public ≠ private: treat the public score as directional, not final.

What the gate checked

single-band float32 · EPSG:32611 · 100 m · 3292×3730 · exact geotransform · finite values in [0,1] · zero NaN/Inf inside the 5,167,373-px footprint · footprint equals the official mask · nodata NaN. See verification.
