What this is

GEMSDOE10 is a complete, tested pipeline that produces a single format-gated GeoTIFF submission for the DOE GEMS Prize Challenge ($300k, closes Dec 3 2026): find hidden faults from geophysical data. Download the file on the home page, upload it on DrivenData, done — details in how to submit.

Why it should win

  1. Right objective. Both rounds score unmapped faults with the catalogue masked. We select models by hidden-fault simulation (system-holdout CV), not catalogue fit — the trap that scored 0.0286 for a 0.17-CV model.
  2. Right features. 107 physics-informed channels: potential-field edges (HGM/ASA/tilt), multi-scale curvature, structure-tensor lineaments, plus new Frangi vesselness + Gabor strike detectors and lidar scarp morphology.
  3. Right emission. Budget-based top-k placement swept in the harness (binary/soft/envelope/halo2 × 1–5%); the winner is gated by 9 format rules before it can be published.
  4. Honest negatives. Catalogue proximity (0.012), SGMC-gap traces (0.0000) and QF-gap (0.003) were measured and excluded — the file contains no known-dead mass.

How to submit (30 seconds)

1. Download the .tif (or .zip) from the home page. 2. Open the competition → Submit → Make new submission. 3. Choose the file, paste the suggested note from the file's sidecar. Full walkthrough: how to submit.

Compliance

Eligibility (§1.3) and the 3-per-week cadence (§3.4) are the account holder's responsibility. AI assistance is disclosed in the repo (AI_DISCLOSURE.md). One submission is chosen blind for both rounds (§3.6).
