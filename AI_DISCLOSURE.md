# Generative-AI disclosure — draft, not a signed assertion

[Rules §3.2](https://docs.nlr.gov/docs/fy26osti/96647.pdf) allow generative AI but require a narrative describing its extent and use. The participant remains responsible for accuracy and authorship representations.

## Current draft (session 5 — describes the currently recommended artifact H28; account holder must approve)

“This project used Arena.ai Agent Mode to review code and published artifacts, retrieve official references, formulate and preregister geological hypotheses, implement feature transforms and validation/publishing tools, run CPU experiments, and draft documentation and the website. Every candidate was tested on four spatially blocked geographic folds (4 km training exclusion, a held-out confirmation fold) before release. The currently recommended submission (H28) is a histogram-gradient-boosting classifier with 166 features: 107 transforms of the supplied rasters, 10 catalogue-continuation features built from the supplied labels and supplied magnetic/elevation rasters, 13 fault-scarp statistics and 36 neighbourhood-context statistics derived from the USGS 3D Elevation Program 1/3 arc-second (~10 m) DEM (public domain; tiles fetched on a GitHub-hosted runner with recorded hashes). Its output is emitted as the across-strike probability ridge of the top 20 % of pixels, kept at every third ridge pixel along strike (binary 0/1 values). The emission choice was decided by a preregistered density-matched holdout protocol motivated by an analysis of the group's own publicly scored artifacts (scores user-reported). Training used the supplied raster labels only — no generative-AI-invented fault labels, no pseudo-labels. No competition upload was made by the agent; public competition scores attributed to the group were provided by the user; authenticated upload associations and private test labels were not available.”

Update again if a different artifact is finally selected (e.g. a future 1 m-lidar model would add the USGS 3DEP 1 m DEM as an external source).
