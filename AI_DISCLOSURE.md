## Review-ready draft (sessions 1–2, update the final model clause before submitting)

“This project used Arena.ai Agent Mode to review code and published artifacts, retrieve official references, formulate geological hypotheses, implement feature transforms and validation/publishing tools, run CPU experiments, and draft documentation and the website. Session 1 tested an odd topographic-step feature (H12) on buffered geographic holdouts; it was measured and rejected. Session 2 implemented and null-calibrated a strip cross-correlation engine (H13) and endpoint-continuation ray features (H16), preregistered a 8-policy spatial validation protocol, and measured both: H13 failed its confirmation fold; H16 beat both matched baselines on development mean and confirmation. Training used supplied raster labels only, not generative-AI-invented fault labels. Feature bytes were restored from a pinned team mirror and checked against inherited hashes. No competition upload was made by the agent; the published download is one-click but unuploaded. Public competition scores attributed to the group were provided by the user; authenticated upload associations and private test labels were not available.”
